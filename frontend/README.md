# Frontend

Aplicação Angular do sistema de notas fiscais.

A documentação completa do projeto (arquitetura, como rodar, detalhamento técnico do desafio Korp) está no [README da raiz do repositório](../README.md)

## Desenvolvimento rápido

npm install
npm start

Abra `http://localhost:4200/`. Os microsserviços de Estoque e Faturamento devem estar em execução (veja o README da raiz).

---

> Scaffold gerado com [Angular CLI](https://github.com/angular/angular-cli) 21.2.21. Comandos úteis do CLI: `ng generate`, `ng build`, `ng test`.
